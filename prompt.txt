Database rules:
1. Use BIGINT UNSIGNED for primary keys where appropriate.
2. Use VARCHAR for short text fields.
3. Use TEXT or LONGTEXT for long content.
4. Use JSON for flexible metadata where appropriate.
5. Use DATETIME for timestamps.
6. Use DECIMAL for scores where precision is important.
7. Define appropriate foreign keys.
8. Add indexes for frequently searched fields.
9. Prevent duplicate vocabulary records using appropriate unique constraints.
10. Use InnoDB storage engine.
11. Use utf8mb4 for all text tables.
12. Design indexes for Chinese vocabulary search, Pinyin search, and Vietnamese meaning search.
13. Use database transactions for examination submission and learning progress updates.
